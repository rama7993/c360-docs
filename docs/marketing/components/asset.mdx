# **📂 Assets**

The **Assets** module in **C360 CRM** helps you organize, manage, and track marketing resources like documents, videos, and infographics.

To access it:  
➡️ Go to **Marketing** → **Campaign Components** → **Assets** from the left-hand menu.

---

Assets can be viewed in **Grid View** or **List View**:

## 🧩Left Panel Components 

<Tabs>


<TabItem value="all assets" label="📜 All Asset">

- The **All Assets** category provides a comprehensive view of every asset available in the system.
- It includes all active items across different categories, enabling users to browse, search, and manage their complete asset library from a single place.

### 🗂️ Actions Available In The All Asset Section


| Column                    | Description                                                                        |
| ------------------------- | ---------------------------------------------------------------------------------- |
| **Edit**                  | Modify asset details such as name, content, or configuration.                      |
| **Download**                  | Download the asset to your local device..                      |
| **Move to Folder**        | Move the asset to a different folder for better organization.                      |
| **Share**                 | Share the asset with users or teams with controlled permissions.                   |
| **Remove from Favorites** | Remove the asset from the Favorites list while keeping it available in All Assets. |
| **Copy**                  | Create a duplicate of the asset for reuse or modification.                         |
| **Manage Tags**           | Add, edit, or remove tags to organize and filter assets efficiently.               |
| **Folder / File Information**    | View details like folder name, owner, and asset count.                             |
| **Move to Trash**         | Move the asset to Trash for temporary storage or permanent deletion.               |
| **Preview**               | Can view the files in the asset without downloading them.                          |

## 🎛️Filtering Assets

You can filter assets by:

- **Category**
- **Type**
- **Created Date**
- **All Asset/ Folder / File**

:::note

- **All Assets**: Visibility of all the assets in the system.
- **Folder**: Visibility of all the Folders in the system.
- **File**: Visibility of all the Files in the system.

:::

  caption="Filtering Assets"
/>

## 📂 Move To Folder

- Select the checkbox for the asset you want to move or click on three vertical dots..
- Click on the **Move to Folder** button.
- Selecte the folder.
- Click on **Move**.

:::note

- You can move both **File** and **Folder** to another folder.

:::


<DocImage
  src="/media/marketing/component/asset/move-to-folder.png"
  caption="Move Assets to Folder"
/>

---

## 📋 Copy 

- Select the checkbox for the asset you want to copy or click on three vertical dots.
- Click on the **Copy** button.
- Select the destination folder.
- Click on **Copy**.

:::note

- You can copy both **File** and **Folder** to another folder.

:::


<DocImage
  src="/media/marketing/component/asset/asset-copy.png"
  caption="Copy Assets"
/>

## 🗑️ Deleting Asset

1. Go to **Trash** section.
2. Select the checkbox(es) for the assets you want to delete.
3. Click the **Delete** icon .
4. Click on **Yes** from the confirmation pop-up if you want to delete.

## ✏️Add or Edit Asset

**To add an asset:**
- Asset categories in two types: **Folder** and **File**. 

<Tabs>

<TabItem value="add_folder" label="📁 Add Folder">

1. ➡️ Click **Create or Upload**
2. Select **Create Folder**.
2. Enter details (**Name, Tag , Description, Folder Color**).
3. Click ** Create**.

<DocImage
  src="/media/marketing/component/asset/add-folder.png"
  caption="Add Folder"
/>

</TabItem>

<TabItem value="add_file" label="📄 Add File">

1. ➡️ Click **Create or Upload**
2. Select **Upload File**
3. Enter details (**Name, Tag,Type, Description**)
4. Upload / Choose the **File** from your system as required.
5. Click **Upload**.

<DocImage
  src="/media/marketing/component/asset/upload-file.png"
  caption="Upload File"
/>

</TabItem>

</Tabs>

:::note

- For adding a tag : Click on tag dropdown , enter text in the search field and click on create.

:::



**To edit an asset:**

1.  ➡️ Click the ** Edit (pencil)** icon for **File** or **Folder** you want to update.
2.  Make necessary changes.
3.  Click on ** Update** .
